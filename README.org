** Features
  - Support aac, alac, flac, isomp4, mp3, ogg, vorbis and wav files.
  - Keybindings for controlling the playback/navigation.
  - Polished UI with a neo-brutalist design and vibrant colors.
  - Playlist support (smart and regular).
  - Light/dark mode with 10 accent colors.
  - CLI args to control the player (or via script).
  - No networking fully offline.
  - Lightweight and fast (relatively).
** Scripting
Beatalvi stores it database as =~/.config/beatalvi/beatalvi.db=
the db can be use to fetch info about tracks/albums/artists etc.\\
Beatalvi has a cli arg =--queue <INT>= which can be to used add tracks via custom scripts.\\
Script for =dmenu= and =rofi= are provided and can be find inside =scripts= directory.
This scripts are written in perl, but you can use any language you want to port/extend these scripts.
